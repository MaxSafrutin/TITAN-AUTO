# Титан Авто — лендинг

## Сценарии лендинга

При каждом новом открытии посетитель выбирает роль продавца или покупателя. Выбор не сохраняется. Преимущества, этапы сделки, сервис и ответы на вопросы меняются в `assets/audience.js`. Массивные разделы свёрнуты; одновременно открыт один раздел.

Выбор менеджера и маршруты реализованы общими диалогами в `assets/site-common.js`. Карта открывается с заданной точкой назначения; источник маршрута пользователь выбирает в приложении карт.

Правила резервного копирования и публикации: [LOCAL_WORKFLOW.md](LOCAL_WORKFLOW.md). Публикация — только после прямой команды владельца.

## Структура

- `index.html` — основная страница сайта;
- `assets/brand/` — логотип и фавикон;
- `assets/images/` — фотографии, используемые на сайте;
- `assets/images/team/` — фотографии сотрудников в WebP;
- `source-materials/` — локальные исходные материалы для дальнейшей работы; папка исключена из Git.
- `DESIGN_SYSTEM_STORIES.md` — дизайн-код для генерации сторис в стиле лендинга.

Фотография площадки в контактах хранится в WebP и загружается отложенно.

## Настройка GitHub Pages

Следующие шаги относятся к настройке хостинга; они не отменяют обязательного подтверждения публикации владельцем.

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Точка входа уже называется `index.html`, поэтому дополнительная сборка не требуется.
