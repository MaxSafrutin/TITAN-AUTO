# Титан Авто

Сайт публикуется на GitHub Pages из репозитория MaxSafrutin/TITAN-AUTO. Для сборки используется GitHub Actions.

## Управление командой

Откройте [форму в GitHub Actions](https://github.com/MaxSafrutin/TITAN-AUTO/actions/workflows/team.yml) и нажмите **Run workflow**. Для этого нужно право записи в репозиторий. Выберите ветку **main**.

- **add** — добавляет человека. Укажите адрес визитки латиницей, имя и должность.
- **edit** — изменяет сотрудника по адресу визитки. Заполните только поля, которые хотите изменить. Дефис очищает необязательное поле.
- **delete** — удаляет сотрудника и его визитку. Укажите адрес визитки.
- **publish** — повторно публикует текущий состав.

Лимит — 10 человек. Визитка и запись в каталоге создаются, если указан телефон. Вводите в форму только данные для публичного сайта. Личная визитка Максима остаётся по старому адресу и не входит в управляемый список.

Изменения записываются в `team-seed.json`. После успешного запуска новый состав виден на лендинге, в каталоге и в окне выбора менеджера. Дождитесь завершения текущего запуска перед отправкой следующей правки.

## Локальная сборка

Выполните `node build-pages.cjs` из папки проекта. Результат появится в новой папке `_site`. Для GitHub Pages выберите **Settings → Pages → Source → GitHub Actions**.
