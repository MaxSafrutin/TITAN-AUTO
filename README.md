# Титан Авто — лендинг

## Персональные визитки

Каталог: https://maxsafrutin.github.io/TITAN-AUTO/managers/

- `managers/aleksandr-belyaev/` — Беляев Александр.
- `managers/aleksey-volgin/` — Волгин Алексей.
- `managers/nikita-kochetov/` — Кочетов Никита.
- `managers/maksim-safrutin/` — Сафрутин Максим.

Каждая визитка — самостоятельная статическая страница с метаданными для отправки ссылки и файлом `contact.vcf` для импорта контакта. Общие стили и поведение находятся в `managers/assets/cards.css` и `cards.js`.

Фотография Максима: `managers/assets/maksim-safrutin.png`. Остальные страницы используют `managers/assets/titan-avatar.jpg`; для добавления персонального фото замените `src` аватара и `og:image` на нужной странице, а также фото в каталоге.

Telegram открывается по рабочему номеру; доступность поиска зависит от настроек приватности менеджера. У Александра Беляева кнопки Telegram нет. Кнопки MAX открывают персональные ссылки `https://web.max.ru/…`, предоставленные менеджерами. У Максима обе кнопки MAX ведут на один профиль.

Отзывы ведут на предоставленный адрес `https://www.avito.ru/profile/rating`. Это общий адрес: для постоянной публичной страницы отзывов компании потребуется ссылка на её профиль Avito.

Одностраничный сайт автомобильного салона «Титан Авто» в Самаре.

## Структура

- `index.html` — основная страница сайта;
- `assets/brand/` — логотип и фавикон;
- `assets/images/` — фотографии, используемые на сайте;
- `assets/images/team/` — фотографии сотрудников в WebP;
- `source-materials/` — локальные исходные материалы для дальнейшей работы; папка исключена из Git.
- `DESIGN_SYSTEM_STORIES.md` — дизайн-код для генерации сторис в стиле лендинга.

Фотография первого экрана оптимизирована в WebP, поэтому страница загружается быстрее и расходует меньше мобильного трафика.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Точка входа уже называется `index.html`, поэтому дополнительная сборка не требуется.
